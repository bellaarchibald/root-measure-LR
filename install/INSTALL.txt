Root Measure LR - Installation Instructions
============================================

Requires macOS (Apple Silicon or Intel) or Windows 10+.
The installer will set up Python 3.12, dependencies, and the app automatically.

Open the Terminal (Mac) or PowerShell (Windows) and paste the command below.


Mac
---
sudo curl -sL https://raw.githubusercontent.com/bellaarchibald/root-measure-LR/stable/install/install.sh | bash


Windows
-------
powershell -ExecutionPolicy Bypass -c "irm https://raw.githubusercontent.com/bellaarchibald/root-measure-LR/stable/install/install.ps1 | iex"


After installation:
  Mac     - Open "Root Measure LR" from Applications or Launchpad.
  Windows - Use the "Root Measure LR" shortcut on your Desktop.

Note: if the original "Root Measure" (without LR) is also installed,
make sure you open "Root Measure LR" specifically - they're separate apps.
